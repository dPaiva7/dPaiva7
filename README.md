### 📂 `>_ ls -la /projetos_confidenciais`

Embora muitos dos meus contratos corporativos estejam sob estrito NDA (*Non-Disclosure Agreement*), aqui estão trechos desclassificados de arquiteturas que construí recentemente:

#### 📦 Sistema de Gestão de Encomendas (Logística Condominial)
Um ecossistema completo para rastreio e notificação autônoma.
*   **Front-end:** Angular 18 + Material UI.
*   **Back-end:** Symfony 6.4 protegido por JWT Auth.
*   **Mensageria & Notificações:** Fila construída com **RabbitMQ** para processamento assíncrono, integrada com a *Evolution API* para disparos de WhatsApp (incluindo geração de QR Code para retirada segura).
*   **Banco de Dados:** PostgreSQL.

#### 🎙️ Projeto "A Decidir" (Plataforma Adaptativa de Idiomas)
Arquitetura robusta desenhada para suportar comunicação humana ao vivo e módulos de estudo imersivos.
*   **Design Arquitetural:** Monolito Modular implementando Clean Architecture. Fronteiras estritas entre *Identity, Learning, Communication e Moderation*.
*   **Tech Base:** PHP + Symfony 7.4 LTS, PostgreSQL com Doctrine (incluindo Doctrine Messenger para Filas/Workers).
*   **Real-time & Áudio:** Integração com **LiveKit** para WebRTC (salas de áudio ao vivo) e Mercure para eventos em tempo real.
*   **Clients:** Desenvolvido prevendo consumo via React (Web) e React Native (Mobile).
